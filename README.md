# CV Website

This project is a simple, static CV/resume website for Efrem Ghebre.

It includes:
- An English CV page: `cv.en.html`
- A Swedish CV page: `cv.sv.html`
- Shared styling: `cv.css`

## Purpose

The project is meant to present a professional profile in a clean, printable HTML format.  
Each language version has the same overall layout and can be opened directly in a browser without any build tools.

## How to use

1. Open `cv.en.html` or `cv.sv.html` in your browser.
2. Use the **Print CV** button to print or save as PDF.

## Project structure

- `cv.en.html` - English version of the CV
- `cv.sv.html` - Swedish version of the CV
- `cv.css` - Shared styles for both pages

## Notes

- This is a static project (HTML + CSS only).
- No installation or dependencies are required.
- To update content, edit the relevant HTML file.
